# 具身智能机器人评价与采购优化

本仓库用于第五届“数学周报”全国大学生数学建模大赛统一赛题的建模、复算与结果展示。

当前分支 `improve-q1-q4` 在原始方案基础上，对问题一至问题四的评价依据、稳健性检验、约束表达和结果展示进行了补充。原始 `main` 分支保持不变，便于对照检查。

## 本次改进概览

### 问题一：产品分类

- 将原先压缩后的少量指标扩展为 14 个标准化特征，覆盖性能、经济性、环境适应性、防爆安全和成熟度。
- 对不同指标组进行平衡，避免某一类指标因字段较多而主导聚类结果。
- 对 `K=2~6` 计算轮廓系数、Calinski-Harabasz 指数和 Davies-Bouldin 指数。
- 根据题面中的三类业务需求保留三分类，同时明确：三分类是结合业务解释后的选择，并非声称其为所有统计指标下的唯一最优解。
- 增加 200 次重采样稳定性检验，以调整兰德指数（ARI）评价分类稳定性。

最终得到三类产品：旗舰型 26 款、性价比型 17 款、特种型 5 款；特种型均具备履带式或防爆属性。

### 问题二：综合评价与排序

- 增加 CRITIC 客观赋权，利用指标差异性和冲突性补充原有主观权重。
- 采用“政策权重 50% + CRITIC 权重 50%”形成组合权重。
- 组合权重为：性能 19.83%、经济性 23.48%、适配性 21.99%、安全性 16.63%、成熟度 18.08%。
- 增加 10,000 次权重扰动分析，检验头部产品排名的稳健性。

综合排序中，R019 得分 77.30，位列第一；R013 位列第二，两者分差约 0.028。扰动实验中 R019 保持第一的比例为 99.93%。

### 问题三：多情景采购方案

- 明确每个站点的物理可达覆盖率上限：

  ```text
  ρ_k^max = Σq_i^max / Σd_i
  ```

- 将有效覆盖率下限写为 `min(85%, ρ_k^max)`，避免对物理上无法达到 85% 的站点设置不可行硬约束。
- 根据题面说明，将 85% 正确处理为软约束，而不是“人工豁免”。
- 补充实际覆盖率、相对物理上限的完成度以及跨情景完成度标准差。

三套方案的主要结果：

| 方案 | 采购数量 | 实际覆盖率 | 物理上限完成度 | 完成度标准差 |
| --- | ---: | ---: | ---: | ---: |
| 成本优先 | 34 | 90.04% | 91.91% | 5.30 个百分点 |
| 均衡方案 | 37 | 95.01% | 96.97% | 4.52 个百分点 |
| 覆盖优先 | 41 | 97.97% | 100.00% | 0 |

### 问题四：滚动采购与预算安排

- 将问题三的可达性判断推广到各年度，逐年设置有效覆盖率下限。
- 增加滚动采购方案与“2027 年一次性采购”方案的正式对照。
- 对比三年服务水平、年度资金占用、三年支出与全生命周期现值。
- 完成 10 组情景的求解与结果输出。

基准方案在三年内采购数量为 `35/3/3`，共 41 台；最终覆盖率为 97.97%，三年支出为 3577.81，全生命周期现值为 3971.55（金额单位与题目附件一致）。

## 复算方法

建议使用 Python 3.10 或更高版本，并安装以下依赖：

```powershell
python -m pip install numpy pandas scipy matplotlib scikit-learn
```

在仓库根目录依次运行：

```powershell
python 问题一/复算.py
python 问题二/复算.py
python 问题三/复算.py
python 问题四/复算.py
```

脚本会读取题目附件并更新相应的 HTML 报告或 CSV 结果。复算后应重点核对产品编号、站点编号、覆盖率、预算和输出行数是否与报告一致。
